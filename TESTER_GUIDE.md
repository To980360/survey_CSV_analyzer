# POC Tester Guide

1. Open the deployed Streamlit app.
2. Upload your own CSV or Excel file, or use `samples/poc_sample.csv`.
3. Read the Preflight Audit before asking for analysis.
4. Ask: `このデータを自分なら最初にどう見るべき？`
5. Then ask one real question you care about.

Please rate 1–5:
- Data understanding
- Analysis planning
- Ability to catch overlooked risks
- Interpretation quality
- Would you use it again?

Also note any moment where the tool was confusing, overly cautious, or confidently wrong.
